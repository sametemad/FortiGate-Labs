# FortiGate Initial Deployment and Configuration

## Overview

This lab documents the initial deployment and configuration of a FortiGate firewall for a small business environment.

## Objectives

- Deploy FortiGate firewall
- Configure WAN and LAN interfaces
- Update firmware
- Secure administrative access

## Environment

### Hardware

- FortiGate 60F

## Initial Configuration

### WAN Interface

Configured WAN interface for internet connectivity.

### LAN Interface

Configured internal network.

Example:

192.168.1.0/24

## Administrative Security

- Changed default password
- Enabled HTTPS access
- Restricted management access

## Firmware Management

- Backup configuration
- Upgrade firmware
- Validate operation

## Validation

- Internet access verified
- Internal connectivity verified
- System logs verified
